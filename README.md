# Woodland Arcade · 复古森林小游戏合集

这是一个复古森林风格的轻量 HTML 小游戏合集，包含四款可在手机浏览器直接游玩的小游戏。合集主页是 `index.html`，每张卡片都链接到对应的 Vercel 游戏部署地址。

## 游戏目录

| 编号 | 游戏 | 玩法 | 手机操作 |
|---|---|---|---|
| 01 | 萤火虫记忆序列 | 记住并复现萤火虫亮起顺序 | 点击光点 |
| 02 | 森林 2048 | 滑动合并相同数字 | 触摸滑动 |
| 03 | 森林消消乐 | 交换相邻元素并完成连消 | 点击或滑动 |
| 04 | 森林贪吃蛇 | 吃果实、增长并躲避碰撞 | 方向键或滑动 |

## 视觉规范

统一采用深墨绿、苔藓绿、木质棕和泛黄金色，结合森林探险日志、旧印刷品和 1980 年代街机的质感。合集主页为纯 HTML/CSS 静态页面，无构建依赖。

## 维护方式

修改 `index.html` 后可直接部署为静态页面。四个历史游戏当前保留在各自的 Vercel 部署地址中；更新某个游戏时，替换其对应页面并重新部署即可。
